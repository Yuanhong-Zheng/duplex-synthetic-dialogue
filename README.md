# 全双工语音数据生成与评测

[打开展示页](https://yuanhong-zheng.github.io/duplex-synthetic-dialogue/)

页面提供四个独立入口：

- V2.6 管线流程图及「三人短途出行洗漱包取舍」真实案例。
- V2.9 用户对旁人说话与 Stage 2 工程修复：同批中文 100 条，90 条成功、10 条失败保留。
- V1.4 / V1.5 · MineCPM：44 条英文训练案例，含最新双向流式音频、逐轮文本和可播放的 token/unit 序列；同一页面可切换 1000ms / 500ms unit，每 unit 均为 16 个正文 token，V1.5 将外部 TTS_EOS 放在 chunk_eos 后、unit 结束前，下一 unit 转 LISTEN；可切回 V1.4。
- 全双工 Benchmark 调研报告及推荐评测组合。

MineCPM 完整混音使用 96 kbps 双声道 MP3；用户输入保留原始单声道 WAV，以支持按 unit 精确截取试听。原始训练录音和监督标签不受公开试听压缩影响。

V1.4 的两种 unit 时长与 V1.5 复用同一套公开音频，500ms 仅重新划分训练目标、字幕与标签，不重复上传录音；原 TTS 的真实供字测量仍为 16 token / 1000ms。

V2.9 成功案例音频从原始立体声 WAV 转为 48 kbps 双声道 MP3，保留左右声道，按需加载。原 V2.8 展示内容保留在 Git 历史，原始数据和生成代码未在此展示仓库修改。

为提高部署可靠性，原始记录按路径分片并由案例页按需读取；完整资料仍可下载。直接访问单条记录链接前需先访问一次案例页。

案例音频与流程记录分片由同仓库固定提交的 GitHub 原始文件地址按需提供，页面仍在原 GitHub Pages 网址。
