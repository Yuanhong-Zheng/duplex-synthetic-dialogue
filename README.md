**N029-R01-V01 · 三人短途出行洗漱包取舍**。

15个主轮，3次打断、5次附和、1次旁人说话、1次离散流水声和1层持续底噪。

所有台词及事件来自真实冻结结果；属于预设目标行为数据，不是实时策略评测。
